Backup & restore
Export all your data to a file — import it any time to restore everything
Data safety

Exporting saves everything — tasks, history, contacts, quotes, parking lot, done log, costing rates — into a single .json backup file on your Mac. Do this weekly. If you ever switch browsers, get a new Mac, or accidentally clear Safari data, import the backup file to restore everything instantly.

How to use: Click Export → a file named IGNITE-backup-[date].json downloads to your Mac. Move it to your IGNITE folder alongside the app. To restore: click Import, select the .json file, done. All data returns exactly as it was.
